# PowerChat Global

Открытый международный чат, который работает в терминале Windows PowerShell 5.1 и PowerShell 7, используя Supabase. Регистрация, email и пароль не нужны: при первом запуске человек один раз выбирает ник, который сохраняется на устройстве.

Новые сообщения от других участников показываются системным уведомлением Windows в правом нижнем углу. История при входе и собственные сообщения уведомлений не создают.

## Установка из интернета одной командой

Откройте Windows PowerShell и вставьте:

```powershell
irm https://raw.githubusercontent.com/orelavvalero-cell/PowerChat-Global/main/install.ps1 | iex
```

После установки чат запускается командой:

```powershell
powerchat
```

Повторный запуск интернет-команды безопасно обновляет установленный клиент до последней версии.

## Подготовка Supabase

1. Откройте проект Supabase.
2. В разделе **Authentication** включите техническую настройку **Anonymous Sign-Ins**. Она не показывается участникам и нужна только для выдачи защищённого внутреннего ID.
3. Откройте **SQL Editor**, создайте новый запрос, вставьте целиком содержимое `supabase-setup.sql` и нажмите **Run**.
4. Убедитесь, что запрос завершился без ошибок.

SQL создаёт профили, сообщения, жалобы, блокировки, RLS-защиту и серверные ограничения против спама. Не отключайте RLS и никогда не помещайте `service_role` в клиент.

## Первый запуск

В Windows уже есть подходящий PowerShell 5.1. Также поддерживается PowerShell 7.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\PowerChat.ps1
```

При первом запуске пользователь выбирает уникальный ник. Ник и техническая сессия сохраняются на его устройстве, поэтому при следующих запусках ничего вводить не нужно.

## Установка команды `powerchat` в Windows

Из папки проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

После этого откройте новое окно терминала и запустите:

```powershell
powerchat
```

## Команды внутри чата

- `/help` — помощь;
- `/nick НовоеИмя` — изменить ник;
- `/delete 123` — удалить своё сообщение с номером 123;
- `/report 123 причина` — пожаловаться на сообщение;
- `/clear` — очистить экран;
- `/quit` — выйти.

## Безопасность установки

Перед запуском интернет-скрипта пользователь может проверить открытый исходный код `install.ps1` и `PowerChat.ps1` в этом репозитории. В клиенте находится только публичный Supabase `anon`-ключ; административный `service_role` не используется.

## Модерация

В конце `supabase-setup.sql` есть готовые примеры блокировки пользователя, разблокировки и удаления сообщения. Жалобы хранятся в таблице `reports` и недоступны обычным участникам.

Supabase не удаляет старые анонимные аккаунты автоматически. Для крупного публичного чата позже следует добавить плановую очистку неактивных аккаунтов и CAPTCHA-проверку.
